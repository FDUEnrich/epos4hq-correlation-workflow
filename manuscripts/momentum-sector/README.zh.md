## 这里的“按动量分区”是什么

使用每个粒子的横向动量方位角 `atan2(py, px)`，要求两个粒子均落入相对于模型事件平面平行或垂直的同一对顶双扇区；同侧扇叶与相对扇叶均接受。**产生位置不参与分区**，也不是旧版 formation-(x,y) 选区。稿件另包含张角、赝快度和横动量选择扫描。

1. **这是一份历史初稿，不是当前 r4 分析的结果报告。** 其数据批次、中心度、统计方法与配对定义应以稿内说明及原历史项目为准，不能反向从当前代码推断。

3. 稿内中心度按各系统样本的最终稳定态多重数排序；**不是**当前独立最小偏置样本标定的前向带电多重数中心度。
4. 该版 OS−SS 附录先将汇总的 OS、SS 各自归一化为单位面积，再相减：`D = P_OS - P_SS`。结果带符号，积分为零，不再做净面积归一化。附录下栏为两个方向差谱之比，不是 OS/SS 比。
5. 上述附录算法既不同于当前仓库 r4 的“逐事件原始配对差汇总，最后面积归一化”，也不同于后来要求的“每个正净面积事件先归一化，再平均；零／负面积单列”。
6. 稿件使用每系统 64 个输入分片的删除单分片统计估计，不应误称为当前联合事件／MB bootstrap 的误差。

2026-11-20 本地测试环境：Python 3.12.14、NumPy 2.5.4、uproot 5.7.7。该环境只用于本次重构比较，不替换服务器 Python 3.6 的冻结环境。

来源证据格式、事件身份、两腿及排序、缺失中间阶段、重复/未知/矛盾标签、origin4 分层、角度周期边界、方向与切选、并列中心度哈希、OS/SS 唯一配对、联合协方差、批处理依赖环境、HQ-scoped iskip 覆盖、只读缓存复用。

- 原始、零净面积和负净面积 ROOT 输出的 bin、误差及状态一致。

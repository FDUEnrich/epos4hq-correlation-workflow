# 历史设置与尚未完成的工作

这些问题被保留以复现旧样本，不是“优化后已经物理修正”。

1. PbPb 的 `maproj=matarg=207`，不是 208。服务器实际 ROOT 头也为 207。修改为 208 必须生成新样本并重新标定，不能重新命名旧数据冒充。
2. 历史 `hq.i` 的 `iskip=1` 会跳过无重味事件；保存态不是完整 MB。`mb_config.py` 仅在独立 MB 配置副本末尾添加 HQ 参数块中的 `iskip=0`，检查运行日志及完整事件保留，不修改共享 `hq.i`。
3. PbPb `nodecays` 比 OO 多 `250`；列表中部分粒子未列反粒子。EPOS 按带符号 ID 匹配。对最终 D 配对的影响尚需来源/衰变对照，不声称已量化，也不声称因此全部形状无效。
4. `±341` 是 Ds*，基态 Ds 是 `±340`。配置不能不加检查就用于 Ds/D0 产额研究。
5. 两系统 K 因子为 0.9，`ivirtual=1`；这些是模型选择，不是通用“默认无偏设置”。记录完整参数，不能无验证混用新旧样本。
6. 历史组合控制不自动排除所有 beauty feed-down。不能把保存态所有 D0 候选直接称为实验 prompt D0。
7. 该重构保留服务器 r4 的 OS−SS 归一化，不声称已经实现后来要求的“正净面积事件先归一化”。
8. 2026-11-20 核对时，r4 DAG 3884774 已因 MB 生成子任务失败退出。正式 MB 分片仅 OO 51 份/5100 事件通过验收，PbPb 尚无通过的正式分片（pilot 另计）。这里不是已完成的中心度结果，也没有上传或伪造最终结果。
